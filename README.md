# YamBassPlayer

Консольный музыкальный плеер с терминальным интерфейсом (TUI): Яндекс.Музыка, локальная медиатека, радио, визуализация спектра.

## Описание

YamBassPlayer — кроссплатформенный музыкальный плеер с текстовым интерфейсом. Воспроизводит музыку из **Яндекс.Музыки** и из **локальной медиатеки** (папки с файлами), содержит 8 режимов визуализации спектра, 10-полосный эквалайзер, персональное радио («Моя волна»), тексты песен и ASCII-обложки.

## Возможности

- Вход по QR-коду (сканирование приложением Яндекс) или по токену
- Воспроизведение из Яндекс.Музыки с предзагрузкой следующего трека
- Локальная медиатека: добавление папок, сканирование, чтение ID3-тегов (TagLib#)
- Радио: «Моя волна» (персональная и по треку)
- Тексты песен с кэшированием в SQLite
- ASCII-обложки в панели трека, крупном инфо и «Моей волне»
- 8 режимов визуализации спектра в реальном времени
- 10-полосный эквалайзер с сохранением настроек
- 9 тем оформления
- Управление плейлистами: персональные плейлисты, избранное, плейлист дня, умные топы по истории
- Полный контроль воспроизведения (play, pause, stop, prev, next, seek, режимы seq/shuffle)
- Кэширование треков для офлайн-прослушивания
- Избранное: локальное и с синхронизацией в Яндекс.Музыку
- Поиск по локальной медиатеке и Яндекс.Музыке (треки, исполнители, альбомы)
- Командная строка прямо в интерфейсе
- История прослушивания со статистикой
- Кроссплатформенность (Windows, Linux, macOS)

## Установка

### Требования

- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) или выше
- Аккаунт Яндекс.Музыки (вход по QR-коду или токену)

### Шаги установки

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Blesya/YaBassPlayer.git
   cd YaBassPlayer
   ```

2. Соберите проект (в папке, где лежит `.sln`):
   ```bash
   cd YamBassPlayer
   dotnet build
   ```

3. Запустите приложение:
   ```bash
   dotnet run --project YamBassPlayer
   ```

4. При первом запуске откроется окно входа: отсканируйте QR-код приложением Яндекс (или Яндекс.Браузером) либо вставьте токен Яндекс.Музыки. После успешного входа токен сохраняется в `appsettings.json`, и при следующих запусках окно не появляется.

## Получение токена Яндекс.Музыки

Войти можно двумя способами прямо из окна авторизации:

- **QR-код** — по умолчанию. Приложение показывает QR-код, отсканируйте его приложением Яндекс и подтвердите вход; токен подтянется автоматически.
- **Токен** — если QR недоступен. Способы получить токен вручную описаны здесь:

https://github.com/MarshalX/yandex-music-api/discussions/513

## Использование

### Управление интерфейсом

- Навигация: клавиши `↑` `↓` `←` `→`
- `Enter` — воспроизведение трека или выбор плейлиста, двойной клик — воспроизведение
- Поле над списком треков фильтрует текущий плейлист по тексту
- `Alt` — меню, `Ctrl+C` или «Файл» → «Выход» — выход

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `F5` | «Сейчас играет» — полноэкранная визуализация |
| `F8` | Крупное инфо о треке |
| `F9` | «Моя волна» |
| `ё` / `~` | Фокус на командную строку |

### Командная строка

Строка ввода находится под панелью воспроизведения (фокус — `ё`/`~`).

| Команда | Алиасы | Описание |
|---------|--------|----------|
| `play` | `p` | Воспроизвести/возобновить; `play N` — играть N-й трек очереди |
| `pause` | `ps` | Пауза |
| `toggle` | `t` | Пауза/воспроизведение |
| `stop` | `s` | Остановить |
| `next` | `n` | Следующий трек |
| `prev` | `b` | Предыдущий трек |
| `restart` | `r` | Перезапустить текущий трек |
| `seek <0-100>` | | Перемотать на процент |
| `mode <seq\|shuffle>` | | Режим воспроизведения |
| `queue` | `q` | Показать состояние очереди |
| `eq [reset\|<1-10> <0-10>]` | | Эквалайзер: значения / сброс / установка полосы |
| `search [ya] [-t\|-ar\|-alb] <текст>` | `find` | Поиск (по умолчанию локально; `ya` — Яндекс.Музыка) |
| `now` | `track` | Текущий трек |
| `clear` | | Очистить строку результата |
| `likeyandex` | `ly` | Добавить/убрать текущий трек в избранное Яндекс.Музыки |
| `likelocal` | `ll` | Добавить/убрать текущий трек в локальное избранное |
| `help` | `?` | Справка по всем командам |

### Плейлисты

- **Мои треки** — понравившиеся треки Яндекс.Музыки
- **Плейлист дня** и **персональные плейлисты** из аккаунта Яндекс.Музыки
- **Локальное избранное** — избранные треки, сохранённые локально
- **Загруженные** — треки из локального кэша
- **Локальная медиатека** — папки, исполнители и альбомы отсканированной библиотеки
- **Топ 10**, **Топ вечеров**, **Топ по дням** — умные подборки на основе истории

Результаты поиска, «Моя волна» и текущая очередь загружаются как временные плейлисты.

### Меню

- **Файл** → Выход
- **Темы** → выбор из 9 тем оформления
- **Аудио** → Эквалайзер
- **Инструменты** → Локальный поиск, Поиск по ЯМ, Моя волна, Моя волна по треку, Статистика БД, Добавить папку…, Управление папками…, Сканировать библиотеку
- **Вид** → Визуализация, Крупное инфо, Переключить режим спектра, Вид треков (Плитки/Таблица)

### Локальная медиатека

- **Добавить папку…** — добавить папку с музыкой (mp3, flac, ogg, wav, m4a); метаданные читаются из ID3-тегов, при повреждённых тегах — из имени файла
- **Сканировать библиотеку** — индексирует все добавленные папки
- **Управление папками…** — просмотр и удаление добавленных папок
- Исполнители и альбомы локальной медиатеки появляются отдельными ветками в дереве плейлистов

## Архитектура

Проект построен на паттерне **MVP** с внедрением зависимостей через **Autofac** (`ServicesProvider.cs`). Каждый компонент имеет интерфейс (`I*`) и реализацию в подпапке `Impl/`. Слой сервисов (39 интерфейсов) инкапсулирует работу с аудио (BASS), Яндекс.Музыкой, SQLite и локальными файлами; слой презентеров (16) связывает представления (18 интерфейсов) с сервисами. Сквозная логика воспроизведения собрана в `MainWindowCoordinator`, который обрабатывает события `IEventBus` от UI-кнопок и командной строки. Вход в Яндекс.Музыку проходит через окно авторизации (`AuthView` + `AuthPresenter`): QR-код или токен. Данные хранятся в SQLite (`tracks_cache.db`), аудиофайлы кэшируются в `tracks/`, обложки — в `covers/`, настройки (токен, эквалайзер, тема) — в `appsettings.json`.
