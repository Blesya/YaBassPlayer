# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/): новые версии сверху,
на версию один раздел `## [X.Y.Z] — ГГГГ-ММ-ДД`.

Раздел текущей версии целиком уходит в описание GitHub-релиза и в окно «Найдена новая
версия» в приложении, поэтому пишем коротко и для пользователя: что изменилось и что
он почувствует, а не список файлов. Раздела нет — релиз не соберётся: версия в
`YamBassPlayer/Directory.Build.props` и раздел здесь поднимаются одним коммитом.

## [1.2.0] — 2026-10-22

- Апдейтер готов к обновлению на версию с внешним плагином: принимает `plugins/<id>/*`, `.deps.json` и `.runtimeconfig.json`, сохраняет раскладку папок и удаляет устаревшие файлы плагина
- Апдейтер копирует в temp весь набор `YamBassPlayer.Updater.*`, а не только exe

## [1.1.0] — 2026-10-20

- Полноцветные обложки: свой TrueColor-драйвер терминала вместо 16 цветов
- Панель «Инфо» во всю высоту окна — текст песни виден целиком
- Спектр рисуется ровно по ширине списка треков и больше не заходит под панель «Инфо»
- Дерево плейлистов сворачивается кнопкой `[««]` и отдаёт колонки списку треков; состояние запоминается
- Нижние рамки панелей больше не заезжают под панель управления

## [1.0.0] — 2026-10-20

- Первый публичный релиз: Яндекс.Музыка, локальная медиатека, «Моя волна», тексты песен, ASCII-обложки
- 8 режимов визуализации спектра, 10-полосный эквалайзер, 9 тем оформления
- Плейлисты, избранное, поиск по медиатеке и Яндекс.Музыке, история прослушивания со статистикой
- Окно «О треке»: доступность и метки, кредиты, описание исполнителя
- Автообновление через `YamBassPlayer.Updater` и проверка релизов GitHub
