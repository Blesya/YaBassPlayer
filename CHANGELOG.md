# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/): новые версии сверху,
на версию один раздел `## [X.Y.Z] — ГГГГ-ММ-ДД`.

Раздел текущей версии целиком уходит в описание GitHub-релиза и в окно «Найдена новая
версия» в приложении, поэтому пишем коротко и для пользователя: что изменилось и что
он почувствует, а не список файлов. Раздела нет — релиз не соберётся: версия в
`YamBassPlayer/Directory.Build.props` и раздел здесь поднимаются одним коммитом.

## [2.0.5] — 2026-10-27

- Интерфейс отзывается на клавиши сразу: убрана задержка ввода до 100 мс
- Визуализация больше не перерисовывает весь экран 60 раз в секунду: картинка плавнее, терминал и процессор нагружены заметно меньше
- Движение мыши по окну больше не подтормаживает интерфейс: события приходят только при нажатой кнопке
- Список треков и фильтр быстрее на больших плейлистах; бегущая строка не крутится, когда не нужна
- Старт трека не подвисает: снимок плейлистов сохраняется в фоне

## [2.0.4] — 2026-10-27

- Поиск по Яндекс.Музыке запускается с клавиатуры: Enter в поле запроса начинает поиск, Enter в списке результатов добавляет отмеченные треки

## [2.0.3] — 2026-10-27

- Поиск по Яндекс.Музыке больше не роняет плеер: окно поиска открывается в основном цикле интерфейса

## [2.0.2] — 2026-10-23

- «Моя волна» больше не закрывает плеер сразу после запуска: окно станции открывается в основном цикле интерфейса
- Исправлена отправка обратной связи радиостанции: прослушивания и пропуски снова доходят до Яндекса и учитываются в подборе

## [2.0.1] — 2026-10-22

- Состав плейлиста снова кешируется на время запуска: повторный выбор плейлиста в дереве не перезапрашивает список треков у источника

## [2.0.0] — 2026-10-22

- Плагинная архитектура: ядро больше не знает про Яндекс.Музыку, источник подключается плагином
- Меню «Плагины»: у каждого плагина свои пункты и «Настройка»; сломанный плагин виден как `<Имя> (ошибка)`
- Приложение запускается без аккаунта: без входа дерево показывает источники и подсказку «Настройте источник»
- Локальная музыка стала встроенным плагином, Яндекс.Музыка — внешним (`plugins/yandex-music/`) и обновляется вместе с приложением
- «Локальное избранное» — один список в таблице `favoriteLocalTracks`; пользователь сам добавляет туда треки любого источника, лайки Яндекса остаются отдельными «Моими треками»
- Кнопка «В избранное»/«Из избранного» — действие над текущим треком, панель рисует действия, объявленные плагинами
- Вход в Яндекс.Музыку перенесён в «Плагины → Яндекс.Музыка → Настройка»; токены хранятся в `Plugins:yandex-music`
- Данные обновляются автоматически: снимок плейлистов v2, история и кэш треков/обложек по источникам

## [1.2.0] — 2026-10-22

- Апдейтер готов к обновлению на версию с внешним плагином: принимает `plugins/<id>/*`, `.deps.json` и `.runtimeconfig.json`, сохраняет раскладку папок и удаляет устаревшие файлы плагина
- Апдейтер копирует в temp весь набор `YamBassPlayer.Updater.*`, а не только exe

## [1.1.0] — 2026-10-20

- Полноцветные обложки: свой TrueColor-драйвер терминала вместо 16 цветов
- Панель «Инфо» во всю высоту окна — текст песни виден целиком
- Спектр рисуется ровно по ширине списка треков и больше не заходит под панель «Инфо»
- Дерево плейлистов сворачивается кнопкой `[««]` и отдаёт колонки списку треков; состояние запоминается
- Нижние рамки панелей больше не заезжают под панель управления

## [1.0.0] — 2026-10-20

- Первый публичный релиз: Яндекс.Музыка, локальная медиатека, «Моя волна», тексты песен, ASCII-обложки
- 8 режимов визуализации спектра, 10-полосный эквалайзер, 9 тем оформления
- Плейлисты, избранное, поиск по медиатеке и Яндекс.Музыке, история прослушивания со статистикой
- Окно «О треке»: доступность и метки, кредиты, описание исполнителя
- Автообновление через `YamBassPlayer.Updater` и проверка релизов GitHub
